# DevCore

RPG medieval em pixel art em que você aprende a programar (Python e JavaScript) derrotando vilões com código de verdade.

O jogo fica em [`devcore/`](devcore/README.md): lá estão as instruções completas (como rodar, estrutura, como adicionar conteúdo, Firebase e deploy).

```bash
cd devcore
npm install
npm run dev
```

O deploy no Vercel usa o `vercel.json` desta raiz (Root Directory = raiz do repositório).
